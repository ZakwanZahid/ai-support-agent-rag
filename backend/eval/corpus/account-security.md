# Account and security

## Password requirements

Passwords must be at least twelve characters and contain a number. We do not
enforce special characters, because length matters more than symbol variety.

## Resetting a password

Use the "forgot password" link on the sign-in page. The reset link is valid for
one hour. If it expires, request a new one; old links cannot be reissued.

## Two-factor authentication

Two-factor authentication is available using an authenticator app. SMS codes are
not supported, because SIM swapping makes them a weaker second factor than a
time-based code.

## Suspicious activity

If you see a sign-in you do not recognise, change your password immediately and
contact support. We keep sign-in history for 90 days and can tell you the country
and device used.

# Returns and exchanges

## Starting a return

Returns are started from the order page in your account. Print the returns label,
attach it to the parcel, and drop it at any post office. You have 30 days from
delivery to post the return.

## Who pays for return postage

Return postage is free if the item arrived damaged or was not what you ordered.
If you simply changed your mind, £2.95 is deducted from your refund to cover the
label.

## Exchanges

We do not process direct exchanges. Return the original item for a refund and
place a new order for the replacement. This is faster than an exchange because
the new order ships immediately rather than waiting for the return to arrive.

## Faulty items

An item that develops a fault within six months is replaced free of charge. After
six months the warranty terms apply instead.
